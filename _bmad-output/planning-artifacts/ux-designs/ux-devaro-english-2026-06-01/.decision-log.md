- Intent: redesign the existing Devaro English site using the supplied advertising banner only as a style reference.
- Imported visual reference: `imports/site-template-style-reference.jpg` copied from `public/site-templste.jpg`.
- Existing product surface observed: responsive Vue landing page with Ukrainian and English locale toggle, navigation, hero, stats, programs, lesson flow, teachers, pricing, social proof, and contact sections.
- Candidate visual vocabulary visible in the supplied reference, pending user confirmation: torn-paper collage, black grid areas, photocopy halftones, oversized condensed type, dark green blocks, and pink highlights.
- Confirmed: interpret the banner's styling for the existing site rather than copying its words or composition.
- Confirmed visual vocabulary: torn-paper backgrounds or section treatments, sticker-like halftone graphics, dark green structural color, and pink accents.
- Preserve the current content, bilingual behavior, information architecture, and site logic. Avoid unrelated changes outside the visual redesign.
- Workflow mode: coaching path.
- Quality posture: consumer-facing best-effort redesign. Do not reduce the design effort based on stakes classification.
- Confirmed: do not bind `{implementation_artifacts}/spec-devaro-english-conversion-site.md` as a UX source. Existing implementation constraints such as Tailwind and `@iconoir/vue` are already visible in the codebase and do not need to drive the visual contract.
- Confirmed: create a new decorative sticker asset family inspired by the reference banner. Stickers are independent decorative elements placed selectively across the site, similar in purpose to the existing floating learning icons.
- Confirmed: preserve the existing teacher-section names, roles, copy, and photos. Do not apply a halftone filter to teacher portraits and do not replace them with sticker illustrations.
- Confirmed visual register: clean with selective collage accents. Use torn-paper and sticker treatments at key moments rather than applying a dense poster treatment to every section.
- Direction preview feedback: the first-pass header and buttons read too strict and business-like.
- Refine toward an approachable learning site for students, teens, and children without becoming overly childlike.
- Text sticker badges should use tighter padding.
- Direction preview feedback: component styling became inconsistent after softening only the header and buttons.
- Refine the whole component system together. Use one collage-friendly shape language across navigation, buttons, labels, cards, and panels: square printed-block edges, subtle irregular rotation only for accent pieces, and restrained offset shadows on interactive or featured elements.
- Direction preview feedback: rounded corners are not appropriate for this visual language. Torn silhouettes and rotated printed blocks provide softness; UI elements should remain square-edged.
- Header navigation hover should use a green underline with no background fill.
- Lighten the primary green while preserving a grounded dark-green identity.
- Direction preview feedback: outlined content cards read too rigid. Remove card borders; use paper-surface contrast and restrained offset shadows instead.
- Secondary cards should use a clearly green offset backing layer rather than a translucent shadow.
- Comparison pass requested: test pink offset backing layers on secondary cards.
- Confirmed: use solid pink offset backing layers for paper cards, matching the featured quote card. Reserve green for primary structure and actions.
- Confirmed decorative sticker subjects: megaphone, hand holding a marker, headphones, open book, and globe.
- Generated preview sticker family with built-in image generation, then locally removed chroma-key backgrounds. Transparent review assets live under `.working/stickers/transparent/`.
- Sticker generation direction: isolated editorial collage cutouts; black-and-white photocopy halftone grain; slightly imperfect white sticker edge; restrained dark-green or pink print accents; no text.
- Open typography decision: confirm condensed uppercase treatment for major headings with readable sans-serif body text.
- Confirmed: keep the complete generated sticker family without regeneration.
- Confirmed typography direction: condensed uppercase major headings with readable sans-serif body text.
- Promoted approved visual references to `mockups/home-selective-collage.html` and `mockups/stickers/`.
- Verified intended text contrast ratios: white on primary green `5.85:1`; ink on paper `13.11:1`; muted text on paper `5.60:1`; ink on pink `5.56:1`; white on ink `14.40:1`.
- Validation reconciliation: committed `Oswald` display typography and `Inter` body typography with Cyrillic coverage; added prohibited white-on-pink pairing; defined focus outlines, pointer target minimums, decorative safe zones, reduced-motion scrolling, locale semantics, and explicit mobile navigation behavior.
